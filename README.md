# College Management System

A simple **College Management System** developed in **C++** to manage student, faculty, course, attendance, result, and fee information.

## Features

* Student Management

  * Add Student
  * View Students
  * Search Student
  * Update Student
  * Delete Student

* Faculty Management

  * Add Faculty
  * View Faculty
  * Search Faculty
  * Update Faculty
  * Delete Faculty

* Course Management

  * Add Course
  * View Courses
  * Search Course
  * Update Course
  * Delete Course

* Attendance Management

  * Add Attendance
  * View Attendance
  * Search Attendance

* Result Management

  * Add Result
  * View Results
  * Search Result
  * Automatic Grade Calculation

* Fees Management

  * Add Fee Details
  * View Fee Details
  * Search Fee Details
  * Remaining Fee Calculation
  * Payment Status

* File Handling

  * Data is stored in `.txt` files.
  * Data is loaded
